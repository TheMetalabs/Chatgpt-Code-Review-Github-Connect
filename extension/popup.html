Ashlar bridge

Same Chrome where ChatGPT or Grok is signed in. Polls Ashlar and sends the review prompt.

Limits managed browser resources, not total personal ChatGPT/Grok tabs. Completed sources can be archived before formatting finishes. Increasing this does not fix unsaved responses.

Must match ASHLAR_EXTENSION_UPDATE_PORT used by the local updater helper.

Connection

Job polling

Retires jobs the server has cancelled or forgotten (after a restart): a review tab still open is closed unless you used it, and a fix tab without a delivered answer is kept. Also reports long-stalled jobs whose tab is gone as failed; a stalled job with an open tab is left alone.

Last resort: drops every tracked job (recovery, cleanup, saved replies, pending JSON) and reloads the bridge so the in-memory registry is discarded. Use when "Clear stuck jobs" cannot remove leftover jobs whose tabs are already closed. Settings are kept.

Extension update

A durable maintenance lock freezes new admission and tab allocation before files are changed.
